🖥️ 1. O que é uma "Tela" em um Aplicativo?

💡 Conceito-chave: Uma tela é um conjunto de elementos visuais (HTML) organizados por estilos (CSS) que respondem a interações do usuário (JavaScript). Em aplicações web, cada "tela" geralmente é uma <div> com id próprio, que pode ser exibida ou ocultada conforme a necessidade.

🔄 Ciclo de vida de uma tela

Toda tela passa por 4 etapas fundamentais no desenvolvimento front-end:

1. Estrutura

HTML

Define os elementos visíveis: títulos, campos, botões, imagens.

2. Estilo

CSS

Aplica cores, espaçamentos, bordas e posicionamento.

3. Comportamento

JavaScript

Reage a cliques, digitação e mudanças de valor.

4. Transição

Troca de Tela

Alterna entre telas com display: none/block ou classes CSS.

🚀 2. Splash Screen – A Tela de Abertura

A Splash Screen é a primeira tela que aparece quando o aplicativo é aberto. Ela serve para:

  • Mostrar a identidade visual (logo, nome do app).
  • Exibir uma mensagem de carregamento ("Carregando...").
  • Dar tempo para o sistema se preparar antes de mostrar o conteúdo principal.
⏱️ Como funciona? Usamos setTimeout() para agendar a troca de telas após alguns segundos. Cada setTimeout executa uma função depois de um tempo determinado (em milissegundos).

🎯 Estrutura de uma Splash Screen funcional

Tela 1

Splash (#splash)

Visível ao abrir. Mostra "Carregando..." e depois mensagens de progresso.

Tela 2

Conteúdo (#conteudo)

Começa com display: none. É exibida após 3 segundos.

Transição

setTimeout()

Agenda a troca: splash desaparece, conteúdo aparece.

🧠 Detalhamento completo do Splash:
  1. 0s: A tela #splash aparece com "Carregando...".
  2. 1s: A mensagem muda para "⚙️ Preparando...".
  3. 2s: A mensagem muda para "🚀 Quase pronto...".
  4. 3s: A #splash recebe display: none e a #conteudo recebe display: block.

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">

Temos dois cards no <body>:

  • #splash — visível ao abrir. Contém o título do app e <p id="mensagem">.

Usamos 3 chamadas de setTimeout():

  3. 3000ms (3s): esconde #splash e mostra #conteudo

Cada setTimeout(função, tempo) agenda a execução de uma função após tempo milissegundos.

🔄 Fluxo de Funcionamento
  1. Página carrega → usuário vê #splash com "Carregando..."
  2. Após 1s → "⚙️ Preparando..."
  3. Após 2s → "🚀 Quase pronto..."
  4. Após 3s → #splash desaparece, #conteudo aparece

🎵 Lab 2: Playlist Musical com Navegação

Desafio de Teste: Navegue pelas 3 músicas da playlist com os botões ⬅️ e ➡️. Observe como a variável numero controla qual música é exibida na tela.
📄 lab2-playlist-musical.html 
<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Playlist Musical</title>
    <style>
        body { text-align: center; background: #f5f3ff; font-family: sans-serif; padding: 20px; }
        .card { background: white; max-width: 320px; margin: 30px auto; padding: 18px; border: 2px solid #8b5cf6; border-radius: 12px; }
        img { width: 200px; height: 200px; object-fit: cover; border-radius: 12px; }
        button { padding: 8px 15px; margin: 5px; background: #8b5cf6; color: white; border: none; border-radius: 8px; cursor: pointer; font-size: 1rem; }
        button:hover { background: #7c3aed; }
    </style>
</head>
<body>
    <div class="card">
        <h2>🎵 Minha Playlist</h2>
        <img id="capa" src="https://picsum.photos/id/1015/200/200">
        <p id="titulo">Música 1</p>
        <button onclick="anterior()">⬅️</button>
        <button onclick="proxima()">➡️</button>
    </div>

    <script>
        let numero = 1;
        function mostrar() {
            let capa = document.getElementById("capa");
            let titulo = document.getElementById("titulo");
            if (numero === 1) {
                capa.src = "https://picsum.photos/id/1015/200/200";
                titulo.innerText = "Música 1";
            } else if (numero === 2) {
                capa.src = "https://picsum.photos/id/1016/200/200";
                titulo.innerText = "Música 2";
            } else {
                capa.src = "https://picsum.photos/id/1018/200/200";
                titulo.innerText = "Música 3";
            }
        }
        function proxima() {
            numero++;
            if (numero > 3) { numero = 1; }
            mostrar();
        }
        function anterior() {
            numero--;
            if (numero < 1) { numero = 3; }
            mostrar();
        }
    </script>
</body>
</html>

Um único <div class="card"> com:

  • <img id="capa"> — capa que muda dinamicamente
  • <p id="titulo"> — nome da música

Os atributos id="capa" e id="titulo" são os "endereços" que o JavaScript usa para encontrar esses elementos.

🎨 CSS

Padrão de card centralizado:

  • max-width: 320px — boa largura para mobile
  • margin: 30px auto — o auto centraliza horizontalmente
  • border: 2px solid #8b5cf6 — borda roxa
  • object-fit: cover — a imagem 200×200 preenche sem distorcer
  • button:hover — feedback visual ao passar o mouse
⚙️ JavaScript

Variável de estado: let numero = 1; guarda qual música está sendo exibida.

Função mostrar(): usa if / else if / else para decidir qual capa e título exibir, alterando .src (da imagem) e .innerText (do texto).

Função proxima():

  • numero++ incrementa
  • if (numero > 3) numero = 1; faz o ciclo circular
  • Chama mostrar() para atualizar a tela

Função anterior(): lógica inversa com numero-- e if (numero < 1) numero = 3;

🔄 Fluxo de Funcionamento
  1. Página carrega → numero = 1 (a capa inicial vem do HTML fixo)
  2. Clique em ➡️ → numero = 2 → mostrar() troca imagem/título
  3. Após 3 → volta para 1 (carrossel circular)
  4. ⬅️ faz o mesmo no sentido inverso

  • Atualiza o texto para "🌙 Tema escuro"

  2. Clique em 🌙 Escuro → classe .escuro adicionada → CSS troca as cores automaticamente
  3. Clique em ☀️ Claro → classe removida → volta ao padrão
